# SilverLink 개인정보 처리 개요

> 기관 계약 검토용 · 최종 갱신: 2026-07-30

---

## 1. 수집하는 정보

| 항목 | 수집 목적 | 보관 기간 |
|---|---|---|
| 통화 녹음 파일 | AI 분석(텍스트 변환 · 위험 신호 탐지)에만 사용 | **분석 완료 즉시 파기 (기본값)**. 기관 설정으로 최대 180일 보관 가능 |
| 통화 전사본 (텍스트) | 케어 리포트 생성 · 검색 | 계약 기간 동안 보관. 어르신 삭제 요청 시 즉시 삭제 |
| 어르신 기본 정보 (이름 · 관계) | 담당자 식별 | 계약 종료 후 30일 이내 파기 |
| 사회 연결 점수 · 위험 지표 | 대시보드 표시 · 보고서 생성 | 계약 기간 동안 보관 |

**수집하지 않는 정보:** 어르신 주민등록번호, 금융정보, 위치정보, 어르신 직접 입력 데이터 없음.

## 2. 개인정보 처리 방침

### 2-1. 녹음 파기
- **기본값:** AI 분석 완료 즉시 Supabase Storage에서 원본 파일 삭제, DB에서 파일 경로 제거.
- **옵트인 보관:** 기관 관리자가 30 / 90 / 180일 보관을 선택할 수 있습니다. 보관 파일은 만료일에 자동 삭제됩니다.

### 2-2. 어르신 동의
- 서비스 도입 전 기관이 어르신(또는 보호자)에게 통화 분석 동의를 받습니다.
- 동의 일자 · 방법(서면 / 구두 / 대리)을 SilverLink 시스템에 기록할 수 있습니다.
- 동의 기록은 기관 관리자가 대시보드에서 확인할 수 있습니다.

### 2-3. 접근 통제
- 데이터는 기관 단위로 격리됩니다 (Row Level Security).
- 동일 기관 내에서도 **관리자 / 사회복지사 / 생활지원사** 역할별로 접근 범위가 다릅니다.
- 보고서 열람 · CSV 다운로드 이력이 자동 기록됩니다 (관리자만 조회 가능).

### 2-4. 암호화
- **전송 중:** HTTPS (TLS 1.2+) 강제 적용.
- **저장 중:** Supabase PostgreSQL AES-256 암호화, Storage 서버 사이드 암호화 기본 적용.

## 3. 데이터 위치

| 구성요소 | 위치 |
|---|---|
| 데이터베이스 | Supabase (AWS ap-northeast-2, 서울 리전) |
| 녹음 파일 스토리지 | Supabase Storage (동일 리전) |
| AI 분석 | Google Cloud (Gemini API) — 분석 후 원본 파기, 학습에 사용 안 함 |
| 이메일 발송 | Resend (미국 소재). 이메일 본문에는 어르신 이름 · 케어 요약만 포함 |

---

## 4. 데이터 삭제 요청

기관 관리자는 대시보드 → 설정 → 개인정보 처리 메뉴에서 어르신 단위 삭제를 신청할 수 있습니다.  
삭제 시 녹음 파일 · 전사본 · 보고서 · 기본 정보가 즉시 삭제됩니다.

---

## 5. 법적 근거

- **통화 녹음:** 국내 통신비밀보호법상 통화 당사자(복지사)가 직접 녹음하는 형태로 적법합니다.
- **개인정보 수집:** 정보주체(어르신 또는 보호자)의 동의를 기반으로 수집합니다.
- **처리 위탁:** AI 분석을 위해 Google Cloud에 일부 위탁합니다. 위탁 계약서에 비밀유지 의무가 포함됩니다.

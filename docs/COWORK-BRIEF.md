## 1. 지금 제품 상태 (코드 기준)

### 완료된 기능 (2026-08-12 기준, 전부 Vercel 배포됨)

| 기능 | 설명 | 접근 경로 |
|---|---|---|
| F1 기관 테넌시 | 기관 생성·초대·가입, org_members RLS | 내부 |
| F2 케어 관리 대시보드 | 담당 어르신 목록·상태 한눈에 확인 | `/dashboard/caseworker` |
| F3 배치 리포트 | 어르신별 AI 요약 보고서 자동 생성 (주 1회) | `/dashboard/caseworker` → 리포트 탭 |
| F4 이메일 자동발송 | 복지사 메일로 보고서 발송 (기본 off) | 환경변수로 활성화 |
| F5 붙여넣기 템플릿 | 기관 시스템에 바로 붙여넣기 가능한 텍스트 블록 | 보고서 화면 내 |
| F6 데모 모드 | 영업용 시연 계정, 실제 데이터 없이 동작 | `/demo` |
| F7 개인정보 설정 | 녹음 보관·파기 옵션, 기관 관리자 제어 | 설정 화면 |
| 역할 기반 라우팅 | 로그인 → 기관 소속이면 케어 대시보드로 자동 이동 | 자동 |

### 데모 환경 접근 방법

- URL: `silverlink-ai.vercel.app/demo`
- 시연용 기관 계정 생성: `/api/seed-org` 엔드포인트 (개발자 실행)
- 실제 데이터 없이 UI 전체 확인 가능

### 이메일 발송 활성화 방법

기관 방문 시연 직전에만 아래 설정. 평소에는 절대 건드리지 않음.

```
ENABLE_REAL_EMAIL=true
RESEND_API_KEY=[별도 전달]
EMAIL_FROM=[별도 전달]
```

## 2. 북극성 (변하지 않음)

> **방문요양센터·주간보호센터 20곳에게 월 15만원 구독을 판다. → 월 300만원**

- B2C(자녀 개인 구독)는 메인이 아님. 개인 300가구보다 기관 20곳이 유통·객단가·유지비 모든 면에서 우월.
- 핵심 판매 문장: **"생활지원사가 어르신 30명과 통화한 뒤 기록을 입력하는 시간을, 0으로 만듭니다."**

## 3. 경쟁 포지셔닝

**가장 많이 받을 질문: "네이버 클로바랑 뭐가 달라요?"**

| | 네이버 클로바 케어콜 | SilverLink |
|---|---|---|
| 방식 | AI가 어르신에게 먼저 전화 (로보콜) | 사람(생활지원사)이 건 진짜 통화를 분석 |
| 어르신 경험 | 낯선 AI 목소리에 거부감 있음 | 평소와 똑같이 전화 받기만 함 |
| 점유 | 전국 128~150개 시군구, 약 5만 명 | 0 → 지금 시작 |
| 주요 가치 | 안부 확인 자동화 | 복지사 기록 입력 시간 제거 + 이상 신호 자동 감지 |

**포지션**: 클로바는 AI가 전화하는 영역, SilverLink는 사람이 전화하는 영역. 정면충돌 없음.

## 4. 영업 전략

### 타겟 기관

- 방문요양센터 (전국 약 2만 곳)
- 주간보호센터 (전국 약 5천 곳)
- 우선순위: 생활지원사 10명 이상, 담당 어르신 100명 이상인 중형 기관

### 타겟 리스트 소스

건강보험공단 **노인장기요양 공개 DB**에서 전국 기관명·주소·연락처 무료 조회 가능.
- 국민건강보험 장기요양기관 찾기: `longtermcare.or.kr`
- 엑셀 다운로드 → 지역별 정렬 → 전화번호 추출

### 영업 채널 순서

1. **전화(콜드콜)** — 기관 담당자는 메일을 잘 안 봄. 전화가 유일하게 빠름.
   - 스크립트 필요 (아래 §5 참고)
2. **시연 예약** — "10분만 화면 공유로 보여드릴게요" → `silverlink-ai.vercel.app/demo`
3. **메일로 제안서 발송** — 시연 후 당일, 가격표 + FAQ 포함
4. **파일럿 계약** — 3개월 무료 또는 50% 할인으로 진입, 이후 정가 전환

## 5. Cowork Claude가 만들어야 할 자료

아래 자료가 없으면 영업을 시작할 수 없음. 우선순위순.

### 5-1. 전화 영업 스크립트 (즉시 필요)

**목적**: 30초 안에 담당자 흥미를 끌고 시연 약속을 잡는 것.

포함할 내용:
- 오프닝 (자기 소개 + 연결 요청)
- 핵심 한 문장 ("생활지원사 통화 기록 입력 시간을 0으로 만듭니다")
- 예상 반론 대응 (클로바랑 달라요?, 개인정보는요?, 비용은요?)
- 시연 약속 클로징

### 5-2. 기관 대상 이메일 템플릿

**A타입 — 콜드 메일** (전화 전 또는 전화 안 받을 때)
- 제목, 본문 1페이지 이내
- CTA: 데모 링크 또는 전화 회신

**B타입 — 시연 후 팔로업 메일**
- 본 것 요약 + 가격 + 다음 스텝

### 5-3. 1페이지 제안서

기관장·원장이 5분 안에 읽을 수 있는 분량.

포함 항목:
- 문제 정의 (생활지원사 기록 부담)
- 솔루션 (통화 → AI 분석 → 자동 보고서)
- 차별점 (클로바 대비)
- 가격: 월 15만원 (VAT 별도), 파일럿 3개월 무료
- 개인정보 보호 방침 요약 (1~2줄)
- 연락처

### 5-4. FAQ 문서 (기관 담당자 예상 질문)

반드시 포함해야 할 질문:
1. 어르신이 앱을 깔아야 하나요?
2. 통화를 녹음해도 법적으로 괜찮나요?
3. 녹음 파일은 어디에 저장되나요?
4. 클로바 케어콜이랑 뭐가 달라요?
5. 정부 보조금이나 지자체 연계가 되나요?
6. 계약 기간이 얼마나 되나요?
7. 시스템 교육이 필요한가요?

## 6. 개인정보 대응 — 계약의 실제 관문

기관 담당자가 기능 다음으로 가장 많이 물어보는 것. 반드시 준비된 답변이 있어야 함.

### 현재 구현된 것

- 녹음 원본: **분석 후 즉시 파기** (기본값)
- 보관 원할 경우: 기관 관리자가 설정 화면에서 옵트인 가능
- 데이터 보관 위치: Supabase (AWS ap-northeast-2 서울 리전)
- 접근 제어: 기관별 RLS, 타 기관 데이터 열람 불가

### 아직 미구현 — 계약 전 선결 필요

- **어르신 본인 동의 획득 절차**: 제품 내 동의 흐름이 없음. 기관이 자체 동의서를 받는 방식으로 우선 운영.
- 미구현 사실을 제안서에서 숨기지 말 것. "기관이 자체 동의서 운영 → 향후 앱 내 동의 흐름 제공 예정"으로 투명하게 명시.

### 법적 근거

- 통신비밀보호법 상 **본인 동의** 또는 **상대방 동의** 중 하나만 있으면 녹음 가능
- 생활지원사(통화자)가 사전에 고지하고 통화하는 방식으로 합법적 운영 가능
- 기관 계약 시 이 사실을 안내하는 문구를 계약서에 포함 권장

## 7. 코드 담당(Claude Code)이 지원할 수 있는 것

Cowork Claude가 영업 자료를 만들면서 아래를 요청할 수 있음.

| 요청 가능 항목 | 상태 |
|---|---|
| 데모 계정 생성 (seed-org 실행) | 즉시 가능 |
| 이메일 발송 테스트 (ENABLE_REAL_EMAIL=true) | 기관 방문 시연 직전에 진행 |
| 랜딩 페이지 카피 수정 (silverlink-ai.vercel.app) | 카피 전달 시 즉시 반영 |
| 새 기능 요청 | 유료 파일럿 기관이 직접 요구한 것만 수용 |

**절대 하지 않는 것**: 유료 기관 없이 새 기능 추가, B2C 기능 개발, 기술 스택 교체

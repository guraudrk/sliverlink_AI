# 2026-08-10 개발일지

## 오늘의 요약

Gemini 음성 분석 프롬프트에 화자 분리(Speaker Diarization) 지시를 추가했다. 기존 프롬프트는 "대화를 전사하세요"라고만 요청했기 때문에 AI 요약문에 "한 사람이 다른 사람에게"처럼 화자를 구분하지 않는 표현이 섞여 있었다. 이번 수정으로 Gemini가 통화 녹음을 분석할 때 "어르신: ...", "통화자: ..." 형식으로 화자를 구분해 전사하도록 명시했다. 화자 구분이 불확실한 줄은 "화자미상: ..."으로 표시하고, 전체 줄 대비 화자미상 비율이 30%를 초과하면 `speaker_split_ok: false`로 판정해 대시보드에 경고 배지를 표시한다.

기능을 새로 만든 것이 아니라 이미 있어야 할 프롬프트 요청이 누락된 것을 보완한 수정이다.

## 세션: Gemini 화자 분리 누락 보완

### 요청과 목표

- `docs/2026-08-05_기능발굴_변화추적.md` §10 "안티그래비티 지시"에 기록된 A 작업: 화자 분리 누락 수정
- Gemini가 분석 결과를 반환할 때 전사 텍스트에 화자 레이블이 없는 문제 해결
- DB 스키마 변경 없이 프롬프트 수정 + 타입 추가 + UI 경고 배지만으로 처리

### 구현 및 변경 내용

**`ANALYSIS_PROMPT` 항목 1 교체** — 단순 전사 요청 → 화자 구분 전사 지시:
- "어르신"과 "통화자(복지사·가족)" 두 화자로 구분
- 화자 판단 근거(존댓말 방향, 안부 묻는 쪽이 통화자) 명시
- 확신 불가 시 "화자미상: ..."으로 표시하고 추측 금지
- 항목 2 요약 지시도 "어르신", "통화자"로 지칭하도록 수정

**`AudioAnalysisResult` 타입 확장** — `speaker_split_ok: boolean` 필드 추가

**`analyzeAudio()` 반환값 계산 추가:**
```typescript
const lines = (parsed.transcript ?? "").split("\n").filter((l) => l.trim());
const unknownCount = lines.filter((l) => l.startsWith("화자미상:")).length;
const speaker_split_ok = lines.length === 0 || unknownCount / lines.length <= 0.3;
return { ...parsed, speaker_split_ok };
```

**`/api/recordings/analyze` route.ts** — `ai_summary` JSON에 `speaker_split_ok` 포함

**`calls-client.tsx`** — `parseAiSummary` 반환 타입에 `speaker_split_ok?: boolean` 추가, 전사 섹션에 `speaker_split_ok === false` 시 경고 배지 렌더링

### 문제와 해결 과정

- 발생한 오류 없음
- Gemini가 화자 분리를 지원하더라도 프롬프트에 명시적 요청이 없으면 구분하지 않는 동작 확인
- `speaker_split_ok`를 별도 DB 컬럼 없이 기존 `ai_summary` JSON 블롭에 포함시켜 마이그레이션 생략

### 기술적 의사결정

- **DB 컬럼 신설 vs JSON 블롭 포함**: `ai_summary` 컬럼이 이미 JSON을 저장하고 `calls-client.tsx`가 파싱 중이어서 JSON 내 추가 필드로 처리. 나중에 쿼리 필터가 필요해지면 컬럼으로 승격 가능
- **화자미상 임계값 30%**: "확신 불가" 줄이 소수라면 경고 미표시, 1/3 이상이면 신뢰 불가로 판단

### 테스트 및 검증

- `npx tsc --noEmit` — 에러 없음 (출력 없음 = 통과)
- 실제 녹음 파일 재분석은 기관 방문 시연 전 별도 진행 예정 (실제 오디오 파일 필요)

### 변경 파일

- `src/app/api/recordings/analyze/route.ts`: `ai_summary`에 `speaker_split_ok` 포함
- `src/app/(protected)/dashboard/calls/calls-client.tsx`: `parseAiSummary` 타입 수정, 경고 배지 렌더링
